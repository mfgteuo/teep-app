# Teep

Teep is a modern social-media inspired Flutter app UI with a home feed, discover tab, messages, and profile screen.

## Features
- Modern social feed layout
- Story carousel
- Discover topics cards
- Messages inbox
- Profile screen with stats and gallery
- Material 3 design

## Getting started

1. Install Flutter SDK
2. Run:
   ```bash
   flutter pub get
   flutter run
   ```
